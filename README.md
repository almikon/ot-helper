# ОхранаПро — помощник специалиста по охране труда

Демонстрационный MVP с рабочим кабинетом и пошаговой диагностикой СОУТ. Статический сайт, опубликованный через GitHub Pages.

- Рабочий кабинет: `index.html`
- Помощник СОУТ: `assistant.html`
- Стили и логика кабинета: `assets/`
- Данные хранятся в `localStorage` **только в браузере пользователя**.

## MVP 0.3 — замечания специалистов

- Уточнены четыре категории рабочих мест; отдельная справка по дистанционной и надомной работе.
- Вопрос о наличии рабочих мест различает занятые, вакантные и смешанные.
- Сведения о результатах СОУТ разделены на отчёт и наличие данных во ФГИС; отсутствие обоих источников приводит к отдельным действиям.
- Вопрос об основаниях не показывается безусловно после декларации: сначала проверяется, было ли событие.
- Схема сохранения опроса обновлена до `sout_demo_v2`, чтобы старые маршруты не смешивались с изменёнными правилами.

## Ручная приёмка

1. Другой работодатель → дистанционные есть → **только дистанционные/надомные**: вывод об исключении с оговоркой.
2. Другой работодатель → дистанционные есть → **только обычные**: продолжение к вопросу о служащих.
3. Смешанная категория: продолжение по обычным рабочим местам.
4. Невозможно определить категорию: справка → возврат к выбору; либо проверка данных.
5. Все рабочие места вакантные: отдельный результат без автоматического вывода о необходимости СОУТ.
6. Занятые/смешанные: продолжение к перечню.
7. Ранее проводилась СОУТ → нет отчёта и сведений во ФГИС: отдельный маршрут проверки документов.
8. Ранее проводилась СОУТ → документы есть → дата известна → любой статус декларации → нет событий: результат без запроса основания.
9. При наличии события появляется выбор конкретных оснований.
10. Возврат, сброс, печать и перенос рекомендаций в задачи кабинета.

**Важно:** логика предназначена для экспертной приёмки и не заменяет правовую проверку по действующей редакции закона № 426-ФЗ и ТК РФ. Данные не синхронизируются между пользователями. Не вносите персональные и конфиденциальные сведения.
